A language for humans and AI agents

MIND is an experimental programming language designed for humans and AI coding agents to build software together. Today this prototype parses real .mind files and executes small games in your browser.

Working today: integer-grid movement, collectibles, win conditions, and source validation. The game runs locally in your browser, with no login, model, API key, or backend.

Direction: external agents discovering capabilities through MCP and proposing tested language extensions for maintainer review. Gravity, jumping, a full game engine, and autonomous language evolution are not implemented. This playground does not perform live AI generation.

The Three Stars example was authored by a Codex coding assistant during demo preparation. Inspect the language repository.
