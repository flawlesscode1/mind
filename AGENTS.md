# Instructions for coding agents

MIND is an experimental AI-native game programming language. Read `language/spec.md` before editing `.mind` files. Do not invent supported syntax. Run `npm test` after changing the interpreter. Preserve compatibility with existing examples. External agents may suggest extensions, but must not represent proposals as released features. Only the project's authorized maintainer/release process can publish official language updates. Future proposals should document motivation, semantics, implementation, tests, and compatibility.
